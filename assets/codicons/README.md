The SVGs here are from Microsoft's Codicons
(https://github.com/microsoft/vscode-codicons, `src/icons/`), the icons VS
Code uses, under the Creative Commons Attribution 4.0 International license
(`LICENSE`): `error`, `warning` and `info` for problem severities, `git-fetch`,
`repo-pull` and `repo-push` for the Graph's title bar, `collapse-all` for the tree views, `type-hierarchy`, `references`,
`arrow-swap` and `refresh` for the side bar's hierarchy and signal trace views, `copy` and `check` for the Markdown preview's code blocks, `history` for the agent panel's resume button. Unmodified, except that `references` is cropped to the top left 16×16 of its 24×25 drawing, so it holds up at side bar size; Eshvi draws
them in its theme's colors (`crates/app/src/icons.rs`).

`filter` and `filter-filled` are not from Codicons: they were drawn for Eshvi
in the same 16×16, one-color form.
